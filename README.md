# Blaze's Twitch Mod

## A Minecraft Fabric mod that integrates Twitch chat commands and emotes using [Twitch4J](https://github.com/twitch4j/twitch4j) and [bttv4j](https://github.com/iProdigy/bttv4j)

### Features:
- **Commands that allow chatters to spawn in attacks and buffs!**
  - Some examples include:
  - **!pet wolf**
    - spawns a pet wolf, with possible modifiers! [armored, life-linked (kills player upon death), random collar color!])
  - **!spawn [entity]**
    - spawns an entity of the chatter's choice
  - **!message [mail_message]**
    - if a streamer has a mailbox in-game, chatters can send them mail items with custom messages!
  - **!teleport**
    - teleports the streamer to a random location :)
- **Emote screen**
  - integrates with the **BetterTTV API** to display chat emotes on screen **(supports animated emotes)**
- **Chatter entities**
  - chatters can join in as purple allays to chat with streamers directly, as well as hold blocks/items using the **!hold** command
